이 게임은 뭐예요?

화면에는 색 이름이 크게 보이지만, 글자에 실제로 칠해진 색은 다른 경우가 많습니다. 아래에 있는 색 버튼 중에서 지금 글자에 보이는 색(잉크 색)과 같은 버튼을 빨리 고르면 됩니다. 심리 실험에서 알려진 스트룹(Stroop) 효과와 비슷한 재미를 웹 미니게임으로 옮겼습니다.

플레이 방법

  • 가운데 단어를 보고, 글자 색에 맞는 버튼을 누릅니다. (단어 뜻이 아니라 보이는 색입니다.)
  • 한 스테이지마다 여러 문제가 나오고, 스테이지가 올라갈수록 한 번에 맞출 색의 종류가 늘어납니다.
  • 정답이면 점수가 오르고, 오답이면 점수가 깎입니다. 점수가 0이 되면 게임 오버입니다.
  • 모든 색이 등장한 뒤, 그 다음 스테이지부터는 제한 시간·붉은 화면·아래에서 차오르는 용암 연출이 붙습니다. 스테이지가 올라갈수록 제한 시간이 짧아집니다.
  • 정답·오답·스테이지 진행 등 상황에 맞는 짧은 효과음이 납니다.

어떻게 만들어졌나요?

별도 프로그램 설치 없이 브라우저만 있으면 되도록, HTML · CSS · 자바스크립트만으로 게임을 한 파일에 담았습니다. 화면을 그리고 버튼 클릭을 처리하는 부분은 자바스크립트이고, 색 버튼·타이머 바·용암·붉은 틴트 등은 CSS로 모양을 잡았습니다.

효과음은 음원 파일을 넣지 않고, 브라우저 안에 있는 Web Audio API로 짧은 소리를 즉석에서 만들어 냅니다. 모바일에서도 누르기 편하게 여백·터치 영역·노치(세이프 영역)를 고려해 두었습니다.

온라인에서 플레이할 수 있도록 GitHub Pages에 올려 두었습니다.
